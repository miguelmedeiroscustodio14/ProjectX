# ProjectX

Inicializador independente para Roblox no Windows.

## Recursos
- Interface preta com partículas animadas.
- Ponteiros e mira de Shift Lock personalizados.
- Biblioteca de jogos favoritos.
- Monitor de desempenho.
- Atualizador próprio.

## Download
As versões do ProjectX ficam na aba Releases.
Baixe o arquivo ProjectX.exe.

## Aviso
Projeto independente, sem afiliação com a Roblox Corporation.
